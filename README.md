# SportZone Hub

Build a complete, responsive sports e-commerce website called SportZone with a colourful, modern design using orange, blue, and white.

Customer Website: Include sports products such as cricket bats, footballs, badminton rackets, gym equipment, sportswear, shoes, and fitness accessories. Add product images, prices, categories, search, filters, a shopping cart, and checkout.

Admin Panel: Create a secure admin login and dashboard showing total products, orders, revenue, and low-stock alerts. Allow the admin to add, edit, and delete products, manage prices and stock quantities, manage categories, and view and update customer orders.

Inventory Management: Store stock quantities, update inventory when orders are placed, prevent purchases exceeding available stock, and highlight low-stock products.

Database & Security: Use Supabase for product, inventory, order, and user data. Protect admin features with role-based authentication.

Make all major features functional, mobile-friendly, and ready for GitHub integration and Vercel deployment. Add sample sports products so the website looks complete. Prioritize functionality over unnecessary animations or complex designs.
